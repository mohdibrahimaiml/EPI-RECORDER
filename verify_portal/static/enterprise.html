EPI is a file-first evidence layer for enterprises — not a dashboard login. You get portable cryptographic evidence, org key trust, policy checks, Annex tooling, and CI gates. Optional hosted verify/SCITT for scale. Self-host when you must.

Two commands for your engineer. No dashboards. No API keys required for a pilot pack.

pip install epi-recorder
epi enterprise setup
# record one agent run → your-run.epi
epi enterprise pack your-run.epi
# → send auditor-pack.zip to security / audit

Acceptance gate

What PASS means for security and CI.

Modes

  • Air-gapped seal: EPI_NOTARIZE=0
  • Standard seal: RFC 3161 on by default (network at seal only)
  • Verify / view: integrity + signature offline; identity from local trust store

What PASS means

  • --policy strict → integrity + trusted sealer + completeness
  • --review Binding True → human review bound to sealed evidence
  • Standard-policy WARN with unknown key is expected until trust import
