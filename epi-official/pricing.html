Frequently asked questions

Can I use the open source version in production?

Yes. EPI Recorder is MIT licensed. You can run it in production, modify it, and distribute it. The CLI seals, verifies, multi-signs Annex sections, and can emit Annex PDF reports offline. Paid tiers add hosted verification scale, remote SCITT, API keys, and support — not a different evidence format.

What do I actually get if I pay for Pro?

A higher monthly hosted verification quota (10,000 with an API key), more API keys, access to remote SCITT registration when the service is live, and founder email support. Everything for recording and verifying .epi files offline remains free.

How does the pilot program work?

We enable Pro-level hosted access for about 14 days and schedule an onboarding call: signing keys, first sealed artifact, verify path. No credit card. Afterward you can stay on Open Source, subscribe to Pro, discuss Team volume, or talk Enterprise services.

Do I need a paid tier for EU AI Act Annex IV technical artifacts?

No. The open-source CLI produces Annex IV artifacts with signatures, hash chains, multi-signer approvals, and optional local SCITT receipts. That is technical evidence tooling — not legal advice or a notified-body certification. Paid tiers help when you want hosted scale and support, not because Annex is locked behind a paywall.

Why is multi-sign / CI / PDF free if older pages said otherwise?

Those capabilities ship in the open-source CLI and GitHub Action. We stopped listing them as paid differentiators. Hosted PDF generation over the API is not implemented; use epi annex report --format pdf.

Is EPI SOC 2 or ISO 27001 certified?

The CLI and verification tools run in your infrastructure. We are not claiming SOC 2 / ISO certification for a hosted control plane today. Any future certification would apply to operated services under a written program — not to the offline tools themselves.

What about SSO, managed DID registries, and regulatory adapters?

They are roadmap / consulting topics, not shipped SaaS features. Enterprise customers can fund custom work; we will not list them as product checkmarks until they exist.
