Integrations

Capture from your stack

EPI does not replace your agent framework. It wraps or hooks the run so steps land in a sealed .epi. Core package is Python 3.11+; many integrations are optional extras.

OpenAI

wrap_openai(OpenAI()) — chat capture, streaming-aware paths with known limits.

Anthropic

wrap_anthropic(...) — same wrap pattern for Messages API.

LiteLLM

Global callbacks via enable_epi for multi-provider routing.

LangChain

EPICallbackHandler on chains/agents.

LangGraph

Checkpoint / record_langgraph helpers.

OpenTelemetry

EPISpanExporter — bridge spans into steps.

pytest

pytest --epi plugin — evidence from tests / CI.

AGT

Import/export adapters for AGT-shaped traces.

Guardrails

Optional bridge package for guardrail events.

Gateway proxy

Self-host LLM proxy capture (OpenAI-compatible / Anthropic) via epi gateway.

Minimal path

pip install epi-recorder
# optional: pip install epi-recorder[openai]

from openai import OpenAI
from epi_recorder import record, wrap_openai

client = wrap_openai(OpenAI())
with record("agent.epi", goal="demo"):
    client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": "Hello"}],
    )
