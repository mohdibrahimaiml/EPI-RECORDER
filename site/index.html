Trust Architecture

Three Distinct Answers

The system separates these on purpose. A valid seal is not a moral judgment — and LOCAL identity is not a failed seal.

01 · SEAL

Was this file tampered with?

SHA-256 member hashes + Ed25519 signature over canonical manifest JSON. Offline verify. Zero EPI server dependency.

epi verify · valid seal ≠ known who
02 · IDENTITY

Do we trust who sealed it?

KNOWN (org pin) / LOCAL / NOT_PINNED. Unpinned flags WARN — not claim-ready. Insurers: use --policy strict.

epi keys trust · --policy strict
03 · POLICY

Did the run break our rules?

Optional epi_policy.json + 4-pass fault analyzer. Policy FAULT can sit next to verify PASS — the record is intact; the rules fired.

epi analyze · mechanical rules · human review
